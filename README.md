# Multimodel VS Code Extension 

This project presents a **Multimodel AI Assistant** VS Code extension, designed to supercharge developer productivity and code quality through intelligent automation and adaptive AI orchestration.

## Project Overview
### Features:
- *Code Review assistant*: Automatically reviews code for logic errors, inefficiencies, and style inconsistencies. It provides actionable suggestions aligned with project-specific guidelines, helping teams maintain high-quality, readable, and secure codebases. 

- *Multi model orchestration*: Dynamically routes tasks between multiple AI models (e.g., large cloud LLMs and smaller local ones) for optimal performance, cost efficiency, and data privacy—allowing teams to choose the right intelligence for each task.

- *Local model*: Enables on-device inference for sensitive codebases or offline work, ensuring compliance with organizational security policies while maintaining fast, reliable responses.

- *Progressive knowledge base*: Learns progressively from documentation and past interactions—creating an evolving, context-rich knowledge graph that improves over time and personalizes assistance for each project.

- *Security Scanner*
